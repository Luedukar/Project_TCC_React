# Projeto TCC

Esse repositorio é dedicado ao versionamento do projeto de TCC para o curso de engenharia de software

Atualmente o projeto conta com:

- Sistema completo de login/cadastro otimizado com responsividade para mobile

Tecnologias utilizadas até o momento:

- React (JavaScript, HTML) + Tailwind

Repositirio dedicando ao frontend, contendo todas as páginas do projeto, estilos e API para comunicação com backend
